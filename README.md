# 👟 Website Bán Giày Sneaker (WordPress)

## 📌 Tổng quan dự án

Dự án xây dựng một website bán giày sneaker sử dụng nền tảng **WordPress**, kết hợp plugin WooCommerce và các công cụ hỗ trợ để triển khai hệ thống thương mại điện tử cơ bản.

Website mô phỏng quy trình bán hàng online gồm: hiển thị sản phẩm, quản lý giỏ hàng, đặt hàng và thanh toán.

---

## 🎯 Chức năng chính

- Hiển thị danh sách sản phẩm giày
- Xem chi tiết sản phẩm (hình ảnh, giá, mô tả)
- Thêm sản phẩm vào giỏ hàng
- Quản lý giỏ hàng
- Thanh toán và đặt hàng
- Quản lý đơn hàng cơ bản
- Tìm kiếm và lọc sản phẩm

---

## 🧠 Phần tôi thực hiện

- Cài đặt và cấu hình WordPress trên local/server
- Thiết kế và tùy chỉnh giao diện website bằng theme có sẵn
- Tích hợp và cấu hình plugin WooCommerce
- Thiết lập hệ thống sản phẩm, danh mục và giỏ hàng
- Tùy chỉnh layout bằng Elementor / WordPress Customizer
- Cấu hình toàn bộ luồng mua hàng (end-to-end checkout flow)

---

## ⚙️ Công nghệ sử dụng

- WordPress CMS
- WooCommerce Plugin
- Elementor (Page Builder)
- MySQL (Database của WordPress)
- PHP (WordPress Core)
- HTML / CSS (tùy chỉnh giao diện)

## 📊 Kết quả đạt được

- Xây dựng thành công website bán hàng bằng WordPress
- Hiểu rõ quy trình hoạt động của hệ thống thương mại điện tử (eCommerce)
- Biết cách tích hợp và cấu hình plugin WooCommerce
- Tùy chỉnh giao diện và trải nghiệm người dùng cơ bản
- Nắm được quy trình triển khai website thực tế

---

## 💡 Kỹ năng đạt được

- Quản trị WordPress
- WooCommerce (E-commerce system)
- Thiết kế website thương mại điện tử
- Cấu hình plugin và theme WordPress
- HTML / CSS cơ bản trong tùy chỉnh giao diện
- Tư duy triển khai hệ thống web thực tế

---

## 🚀 Hướng phát triển

- Tối ưu UI/UX giao diện
- Tích hợp cổng thanh toán (VNPay / Stripe)
- Tự xây dựng theme thay vì dùng theme có sẵn
- Nâng cấp sang Laravel hoặc React để xây dựng hệ thống riêng
